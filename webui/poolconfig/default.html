Miner Configuration

This is the basic guide how to setup your miner to this pool.

Getting started

To get started mining and use this pool you need the following:

  • {{ coinName }} Wallet address
  • Crypto mining software that supports {{ coinName }} and algorithm {{ algorithm }}
  • Hardware to run it on (Home PC, CPU/GPU mining rig, ASIC, etc.)

{{ coinName }} Wallet address

A wallet address is needed to payout your shares mined at this pool server.
When your total balance reaches or exceeds the payout threshold, your earnings are automatically sent to this wallet address.


Crypto mining software

To mine at this pool you can use any miner supporting the {{ algorithm }} algorithm or {{ coinName }} coin.
Search for "{{ coinName }} miner software", download it, and configure your miner using the stratum URL below.

Configuration parameters:

  • Stratum URL & Port: stratum+tcp://{{ stratumAddress }}
  • Username: YOUR_WALLET_ADDRESS.WORKERNAME (e.g. YOUR_WALLET_ADDRESS.worker1)
  • Password: x (or leave blank)

    • Optional:
  • Static Difficulty: to mine with a static (fixed) difficulty, use d=xxx as your password in your miner configuration where xxx denotes your preferred difficulty.
