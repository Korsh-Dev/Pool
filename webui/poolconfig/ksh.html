Korsh (KSH) CPU Miner Configuration

Guide on how to configure CPU mining software for the Korsh network (Yespower PoW).

Getting Started with Korsh Mining

Korsh uses the Yespower 1.0 (N=256, r=8) algorithm, designed specifically for efficient CPU mining.

1. Korsh Wallet Address

You need a valid Korsh wallet address to receive payouts. Make sure to double-check your payout address.

2. Recommended Mining Software

  • cpuminer-opt (Linux & Windows) - Supports Yespower
  • SRBMiner-MULTI (Linux & Windows) - Supports Yespower
  • xmrig (with Yespower fork support)

3. Mining Configuration Examples

Example: cpuminer-opt
cpuminer -a yespower -o stratum+tcp://{{ stratumAddress }} -u YOUR_KORSH_WALLET_ADDRESS.worker1 -p x
Example: SRBMiner-MULTI
SRBMiner-MULTI --algorithm yespower --pool {{ stratumAddress }} --wallet YOUR_KORSH_WALLET_ADDRESS.worker1 --password x

Parameters:

  • Stratum URL: stratum+tcp://{{ stratumAddress }}
  • Username: YOUR_KORSH_WALLET_ADDRESS.WORKERNAME
  • Password: x (or d=xxx to request a custom static difficulty)
